WEBSITE KELAS — RUANG TEKNIK KOMPUTER

Isi folder:
- index.html : struktur dan konten website
- style.css  : warna, layout, animasi, dan tampilan responsif
- script.js  : menu ponsel, animasi scroll, menu aktif, dan lightbox galeri

CARA MENJALANKAN:
1. Ekstrak file ZIP jika kamu mengunduh versi ZIP.
2. Simpan ketiga file di folder yang sama.
3. Klik dua kali index.html untuk membukanya di browser.
4. Untuk pengembangan lebih nyaman, buka folder di Visual Studio Code dan gunakan ekstensi Live Server.

CATATAN:
- Foto saat ini mengambil gambar contoh dari Unsplash, jadi koneksi internet diperlukan untuk memuat foto dan font online.
- Ganti foto contoh dengan foto kelasmu. Pada setiap kartu galeri di index.html, ubah URL pada atribut data-full dan src dari tag img. Sebaiknya gunakan foto yang sudah mendapat izin dari orang-orang di dalamnya.
- Edit teks kelas langsung di index.html.
- Website ini masih statis: belum memakai database, login, atau fitur unggah foto.
